# Сімейна кав'ярня

## Опис проєкту

Це сайт сімейної кав'ярні, який я створив для навчання веброзробці.

На сайті можна переглянути інформацію про кав'ярню, подивитися меню напоїв і надіслати повідомлення через форму зворотного зв'язку.

Також є можливість змінювати світлу та темну тему сайту. Для зручності користування з телефона зроблено мобільне меню.

На сайті є вхід для адміністратора. Після входу можна додавати нові напої та видаляти їх із меню. 

Повідомлення, які користувачі надсилають через форму, зберігаються в базі даних.

## Використані технології

- **HTML** — для створення структури сторінки.
- **CSS** — для оформлення сайту та адаптації під різні екрани.
- **JavaScript** — для роботи кнопок, меню та перемикання теми.
- **PHP** — для обробки повідомлень і входу адміністратора.
- **SQLite** — для збереження повідомлень.
- **Git і GitHub** — для збереження проєкту та його змін.

## Інструкція із запуску

Для запуску сайту на комп'ютері потрібно встановити PHP.

1. Завантажити проєкт із GitHub.
2. Відкрити папку проєкту у VS Code.
3. Відкрити термінал у папці проєкту.
4. Запустити локальний сервер командою:

```bash
php -S localhost:8000
```

5. Відкрити браузер і перейти за адресою:

`http://localhost:8000/index.php`

Після цього сайт буде доступний для перегляду.

Для входу адміністратора потрібно налаштувати змінну середовища ADMIN_PASSWORD із власним паролем перед запуском сервера.
